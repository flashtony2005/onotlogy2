## 1. 文档目的
规定各环境的标准部署流程与检查清单。

## 2. 业务/技术背景
依赖 environment-map.md 与 sql-script.md。

## 3. 核心规则 & 约束（重点）
- [强制] 部署前必须核对 changelog、部署文档、回滚方案三件套完整性。
- [强制] 生产部署须双人复核并留痕。

## 4. 详细设计/内容
### 4.1 部署流程
1. 拉取 release 分支与 tag
2. 执行数据库脚本（sql-script.md）
3. 构建与发布
4. 健康检查

### 4.2 上线检查清单
- [ ] changelog 已核对
- [ ] 回滚方案就绪


## 5. 风险点 & 注意事项
- 漏执行 DB 脚本会导致结构不一致。
