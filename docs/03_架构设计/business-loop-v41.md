# Business Loop v41

## 目标

持续寻找更优路径不能只依赖人工逐次点击；但自主循环必须有硬边界和安全停止条件。

## 行为

- 新增 `POST /api/v1/business/run-batch`。
- 每轮仍完整执行 `Discover → Decide → Act → Verify`，并复用既有审批、actor、预算、
  资源、世界一致性和租约闸门。
- `maxSteps` 默认 5，最大 20；达到边界立即返回。
- 任一轮没有安全净收益候选，或发现需要人工/审批的中断恢复队列，立即停止。
- UI 提供“执行至多 5 步”，显示实际完成的安全动作数量。

## 验证

两个可自动执行机会在单步批量后仍保留一个；继续有界批量会执行第二个机会，
并在无候选时追加一轮安全空闲。最终每个机会只有一份 `ActionExecuted` 证据。
