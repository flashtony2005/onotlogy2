## 1. 文档目的
提供按模块拆分的接口文档空白模板，每个模块复制填写。

## 2. 业务/技术背景
依赖 api-restful-spec.md 与 error-code.md。

## 3. 核心规则 & 约束（重点）
- [强制] 文件名规则：module-<模块英文短名>-api.md。
- [强制] 每个接口必须含：请求方式、接口路径、权限要求、请求参数、成功示例、失败错误码、特殊逻辑（缓存/幂等/分页）。
- [强制] 接口前缀统一 /api/v1/（可选 /wb/）。

## 4. 详细设计/内容
### 1.1 获取用户详情
- [强制] 请求方式：GET
- [强制] 接口路径：/api/v1/user/info
- [强制] 权限要求：登录用户
- 请求参数（Query/Body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | long | 是 | 用户 ID |

- 响应成功示例：
```json
{ "code": 0, "msg": "success", "data": { "userId": 1, "username": "lushaohui" } }
```
- 响应失败错误码：WB1001（参数错误）
- 特殊逻辑：缓存 60s，幂等


## 5. 风险点 & 注意事项
- 权限要求漏写会导致越权风险。
