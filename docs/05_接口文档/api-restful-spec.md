## 1. 文档目的
规定接口风格、返回体结构、分页与版本约定的全局规范。

## 2. 业务/技术背景
被所有 module-xxx-api.md 引用。

## 3. 核心规则 & 约束（重点）
- [强制] RESTful 风格，版本放路径 /api/v1/。
- [强制] 返回体统一包装：{ code, msg, data }。
- [强制] 分页统一参数：pageNum、pageSize、total。
- [强制] 所有入参校验规则写在接口文档中。
- [建议] 接口前缀可用 /api/v1/wb/xxx（WB 专有前缀）。

## 4. 详细设计/内容
### 4.1 路径规范
- 资源用名词复数：/api/v1/users
- 版本固定前缀：/api/v1/

### 4.2 返回体结构
```json
{ "code": 0, "msg": "success", "data": {} }
```

### 4.3 分页约定
| 参数 | 类型 | 说明 |
|------|------|------|
| pageNum | int | 页码，从 1 开始 |
| pageSize | int | 每页条数 |
| total | long | 总条数（响应返回） |


## 5. 风险点 & 注意事项
- 返回体结构不统一将导致前端解析层混乱。
