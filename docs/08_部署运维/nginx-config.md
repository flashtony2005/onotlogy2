## 1. 文档目的
规定反向代理、TLS 与静态资源服务的配置规范。

## 2. 业务/技术背景
依赖 docker-compose.md。

## 3. 核心规则 & 约束（重点）
- [强制] 生产必须启用 HTTPS/TLS，禁止明文对外。
- [建议] 配置含健康检查与限流。

## 4. 详细设计/内容
### 4.1 反向代理示例
```nginx
server {
  listen 443 ssl;
  location /api/ { proxy_pass http://app:8080; }
}
```


## 5. 风险点 & 注意事项
- TLS 配置错误会导致安全风险。
