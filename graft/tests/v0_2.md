# tests/v0_2.rs · [[v0-1-v0-3-integration-contract]]

TDD test contract for V0.2 world model covering relation linking, duplicate-edge rejection (REQ-012), and domain event emission (REQ-013).

- tc012_relation_link_and_neighbors · function · L10-L36 — Verifies that linking a relation creates a graph edge, makes the target appear in neighbor queries, and emits a RelationLinked world event bound to both endpoints.
- tc012b_duplicate_edge_rejected · function · L40-L61 — Verifies that re-linking an identical edge is rejected with WB2007 and does not duplicate the stored relation.
- tc013_domain_event_emitted · function · L65-L86 — Verifies that a domain event is persisted as a world trace event and simultaneously published to the event bus with the same payload.
