## 1. 文档目的
定义服务容器化编排与本地/测试环境一键启动。

## 2. 业务/技术背景
依赖 deploy-steps.md。

## 3. 核心规则 & 约束（重点）
- [强制] 镜像版本必须固定 tag，禁止 latest。
- [建议] 配置通过环境变量注入，不写死敏感信息。

## 4. 详细设计/内容
### 4.1 服务编排
```yaml
services:
  app:
    image: registry/app:vx.x.x
```


## 5. 风险点 & 注意事项
- latest 镜像会导致环境不一致。
